## 1. 风格定位

**一句话：手绘本水彩 × 奶油暖调 ——「外婆的午后厨房」。**

三个关键词，所有素材的审判标准：

1. **暖**：阳光、木、炊烟。画面里不允许出现冷灰、纯黑、荧光色。
2. **软**：所有形状圆润化——圆角、圆叶、圆果实、圆笔触。没有尖锐的直线和硬边阴影。
3. **拙**：保留手绘的不完美感——轻微歪斜的线条、水彩的晕染和纸纹、不均匀的涂色。拒绝矢量感的绝对精确。

玩家第一眼应该感到的不是"精致"，而是"想住进去"。

### 为什么是手绘水彩，而不是别的

| 候选风格 | 代表 | 结论 |
|---------|------|------|
| 像素风 | 星露谷 | **不学**。像素需要逐帧手工修，AI 生成像素的可用率极低；且像素受众偏核心玩家，与我们"休闲手机端"用户不重合 |
| 3D 低多边形 | 动森 | **学气质不学形态**。动森的"软、圆、奶油光"是我们的情绪目标，但 3D 管线超出业余产能，且 1.4 已锁定 2D 场景图 |
| 国风水墨/工笔 | 江南百景图、桃源深处 | **部分借鉴**。桃源的水彩晕染和留白要学；但纯国风会把受众收窄，且与"做菜经营"的烟火气不如田园绘本贴合 |
| 手绘水彩绘本 | 旅行青蛙、桃源深处 | **选定**。AI 生成可用率最高、风格容错最好（AI 的不稳定恰好是"拙"）、与暖色田园配色天然契合、和「外婆的食堂」故事严丝合缝 |

### 从成熟游戏各取一件东西

- **星露谷**：作物的**可读性**——每种作物在图标尺寸下 0.3 秒可辨认（剪影 + 主色唯一）。这是功能性底线，美术再好看，分不清番茄和苹果就是失败。
- **动森**：**情绪舒适度**——低对比、无攻击性配色；圆角界面；所有东西看起来"可以摸"。
- **桃源深处有人家**：**水彩质感与留白**——场景大图用晕染做空气感，UI 用宣纸/奶油底做"纸"的感觉。
- **旅行青蛙**：**"小"的智慧**——素材不在多而在情；一个场景里几个有故事的细节（晾着的围裙、窗台上的罐罐）比满屏元素更留人。这直接服务我们的世界观。

## 2. 主色板（全项目唯一色彩来源）

比例原则：**60% 底（奶油/纸）· 30% 景（绿/木/天）· 10% 点（果实与强调色）**。

### 2.1 基底色（UI 与大背景，60%）

| 色名 | Hex | 用途 |
|------|-----|------|
| 奶油纸 | `#FFF8E7` | 面板底、卡片底——所有 UI 的"纸" |
| 米白 | `#FFFDF5` | 卡片内层、列表项底 |
| 浅麦 | `#F5E8C8` | 分区底、次级面板、tab 未选中态 |
| 描边棕 | `#4A3520` | 全局描边与正文文字——**不用纯黑**，所有"黑"都由它代替 |

### 2.2 场景色（画面主体，30%）

| 色名 | Hex | 用途 |
|------|-----|------|
| 晴空 | `#A8D8EA` → `#D9F0E3`（向下渐变到地平线） | 田地页天空，永远白天偏午后 |
| 草地 | `#7EC850` / 深草 `#5CA83C` | 地面、植被；深色只用于投影和层次 |
| 原木 | `#8B5A2B` / 深木 `#6B4423` | 厨房页背景、木架、家具 |
| 泥土 | `#A0724A` / 湿土 `#7C5335` | 地块；湿土=已浇水/生长中的暗示 |

### 2.3 强调色（交互与情绪点，10%，严格限量）

| 色名 | Hex | 用途 |
|------|-----|------|
| 丰收黄 | `#F2B830` | 主按钮、选中态、金币——**全游戏唯一的"行动色"** |
| 番茄红 | `#E8563F` | 新发现！、可收获！、小红点——**只用于"惊喜/可点击"信号**，不做大面积装饰 |
| 暖橙 | `#F08A24` | 次级强调、灶台火苗、黄昏氛围 |
| 莓果粉 | `#F4A7B9` | 草莓/节日点缀，仅素材内部使用 |

### 2.4 色彩纪律

- 每屏强调色（黄+红）出现次数 ≤3 处，多了"惊喜信号"就贬值——**发现新食谱的红必须是全屏唯一红点**。
- 禁止：纯黑 `#000`、纯白 `#FFF`（纸面永远带一点暖）、冷灰、荧光色、高饱和蓝紫。
- 阴影一律用深棕 `rgba(74,53,32,0.2~0.35)`，不用灰黑阴影——冷影子是"暖感"的第一杀手。
- 金色/稀有度的表现走"丰收黄 + 手绘星星贴纸"，不做写实金属渐变。

## 3. 图形语言（Shape Language）

1. **圆角规则**：卡片圆角 16~24px，按钮圆角 24px（胶囊形），图标内元素全部圆头圆身。整个游戏里不允许出现 0 圆角的矩形 UI。
2. **描边规则**：2~3px 手绘感描边（色 `#4A3520`），允许轻微抖动与不闭合——这是"拙"的来源。AI 素材后期统一加纸纹叠层时描边保留。
3. **透视**：场景用**平视绘本透视**（略俯视 15~25°），不用轴侧等距（太"游戏感"），不用写实透视（太硬）。
4. **光**：永恒午后 4 点的阳光。光源方向全项目统一为**左上 45°**，暖橙高光 + 棕调软阴影。所有素材（包括 AI 生成的图标）必须遵守同一光源，否则拼在一起立刻穿帮。
5. **质感叠层**：所有最终素材叠 5~10% 不透明度的水彩纸纹 + 极轻噪点，统一由后期脚本完成——这是"同一套图"的兜底手段。

## 4. 资产分级规范

### 4.1 场景大图（4 张页面背景，远程 CDN 加载）

- 尺寸：1080×1920 出图，压到 720×1280 交付，WebP q80，单张 ≤300KB。
- 构图铁律：**下半 60% 是"留白操作区"**（低细节草地/木地板），视觉细节全部集中在上半 40%（天空、屋檐、远山、炊烟）——因为下半屏要被 UI 和地块占满，细节画在那里是纯浪费还干扰点击。
- 每页一个"故事细节"（服务留存的情感锚点）：
  - 田地：远处外婆家的小屋和烟囱炊烟；
  - 厨房：窗台上晒着的香草、挂着的旧围裙（主线第一章田伯送围裙的回收点）；
  - 商店：门口小黑板手写着歪歪扭扭的"今日特价"；
  - 图鉴：一本摊开的旧笔记本，纸页泛黄——食谱图鉴 = 外婆的手抄本，这个设定让收集行为有了情感主人。

### 4.2 图标（作物/菜品，最高优先级资产）

- 尺寸：512×512 出图，交付 128×128（图鉴/列表）与 256×256（详情/出锅特写）两档。
- 规范：主体占画面 70%、居中、左上光源、无背景（透明 PNG）、描边 2~3px。
- **生长阶段差分**：每种作物固定三帧——幼苗（`<id>_s1`，破土双瓣芽，共用形态）→ 半成株（`<id>_s2`，逐作物形态分化）→ 成熟（原图标）。三帧并排出图、同一光源同一描边，缩到 32px 仍能读出"长大了"。
- **剪影测试**：每个图标缩到 32px 看剪影，分不清就打回——星露谷式可读性是硬指标。验收拼版见 `docs/mockups/icon-sheet.png`（64px 标准档 + 32px 剪影测试档双排出图）。
- 菜品的惊喜感视觉化：普通菜 = 朴素陶碗/盘/杯/串/蒸笼（容器按菜品分化，治"全是碗里色块"）；组合成功的"新发现"首次展示时叠加手绘星星贴纸 + 一圈丰收黄光晕（程序叠层，不画进素材）。

### 4.3 UI 组件

- 字体：**站酷快乐体（ZCOOL KuaiLe，OFL 免费可商用）已定案为全游戏 UI 字体**（2026-08-05 接入）。管线：全量 TTF 存 `art-src/fonts/`（不进包），`npm run subset-font` 用 fonteditor-core 子集化出 `assets/resources/fonts/ui.ttf`（约 105KB，字符集 = 数据表全部字符 + 剥注释后源码全部非 ASCII 字符 + 可打印 ASCII，脚本自带 cmap 缺字检查）；GameController 启动时加载，`applyUiFont` 在页面/列表/抽屉/庆祝层重建后统一重挂，加载失败全体降级系统字。**字库纪律：快乐体无 emoji 与装饰符号（🌟✨🎁→≤★ 等均缺字），UI 文案只用其覆盖字符——装饰感交给 Graphics 图形与动效承担；改 UI 文案后复跑 `npm run subset-font` 验缺字**。兜底：禁用黑体直角的"商务感"字体。
- 组件即"纸与木"：面板=奶油纸卡片（纸纹+棕描边+软投影），按钮=黄色豆形/胶囊，招牌类才用木牌（如商店「丰穗小铺」）。
- **HUD（四页统一）**：左上角「外婆圆形头像 + Lv 等级徽章 + 经验胶囊条（`当前/上限`）」，右上角金币胶囊（丰收黄硬币图标 + 数值 + 加号）。两角贴真实屏幕边缘，不悬空。
- **底部导航**：四个胶囊形 tab（田地/厨房/商店/图鉴），未选中=米白底棕描边，选中=丰收黄填充——全屏唯一一处常驻黄色块，与 §2.4 色彩纪律一致（tab 选中态不计入每屏 ≤3 处强调色配额）。
- **底部弹层（bottom sheet）**：选种子、食材区等"选一样东西"的交互一律用底部上滑弹层——奶油纸大卡、顶部大圆角、标题居中、右上关闭×，网格项=图标+名称+数量/解锁条件（未解锁项置灰 +「Lv× 解锁」角标）。
- 数字反馈：金币增加用丰收黄弹跳数字；收获用作物图标从地块飞向顶部栏的抛物线动画——动效是"爽感"的一半，M4 手感打磨的重点。

### 4.4 未来的 NPC 头像（M5 预留，现在不做）

统一规范提前定死：圆形裁切、胸部以上、正面微侧、表情温和夸张一度（嘴硬心软的田伯要看得出"嘴硬"）。水彩头像 + 奶油色圆框，与图标同管线出图。

### 4.5 页面级视觉规范（原型 v3 定稿，四页各自的生活细节）

- **田地页**：场景=平视农田——左上大树、晾绳挂着的手绘灯笼串（丰收祭伏笔，章节推进时点亮）、右侧外婆小屋 + 木栅栏；地块=圆润微梯形土畦（干土/湿土两态），未解锁地块=草皮底 + 锁形图标 + 地块编号，成熟作物挂「可收获！」番茄红徽章；点空地弹「选择种子」bottom sheet。右上角木牌标注「田地 Lv× · n/m 块地」。
- **厨房页**：原木墙背景（挂旧围裙、窗台瓶罐与香草）；灶台大锅居中，锅内汤色随食材变化；上方组合槽 1/3（已放=图标卡片，空槽=虚位描边）+ 烹饪进度条（`菜名 · 剩余 n 秒`）；「开始烹饪」丰收黄主按钮；底部食材区=bottom sheet 式大卡，网格项带库存数量。
- **商店页**：顶部红白条纹遮阳篷 + 木招牌「丰穗小铺」；「今日特价」门口小黑板（手写字、粉笔感）；售卖区主按钮「全部卖出」；升级区=纵向卡片列表（设施图标 + Lv→Lv + 等级圆点 + 效果说明 + 价格黄色胶囊按钮）。
- **图鉴页**：整页=泛黄手抄本纸底；顶部书签缎带 + 标题「外婆的手抄本」；作物/食谱两个胶囊分页（选中=丰收黄）；已解锁卡=彩色图标 + 名称 + 一角和纸胶带（粉/黄/绿轮换，随手贴感）；未解锁卡=褪色低饱和剪影 + `???`；页脚角落随手画一支铅笔。

## 5. AI 生成管线（风格统一三件套的执行层）

### 5.1 固定风格提示词（英文主提示词，出全套不换模型）

```
hand-painted watercolor storybook illustration, cozy pastoral style,
warm cream and harvest yellow palette, soft rounded shapes, thick brown
outline (#4A3520), gentle paper texture, afternoon sunlight from upper-left,
soft warm shadows, no black, no neon, flat 2D game asset,
[SUBJECT HERE], centered, clean composition
```

负面提示词：

```
photorealistic, 3d render, pixel art, sharp edges, dark, cold colors,
gray, black, neon, gradient mesh, realistic shadow, text, watermark
```

- 模型锁定一个（建议 SDXL 水彩 LoRA 或即梦/Midjourney 的 niji 模式），**全套资产同一模型同一 seed 段**；
- 先出 7 个作物图标做"小样验收"（对应方案 6.2 风险 2），剪影测试 + 拼版测试通过后才放量生成菜品与场景。

### 5.2 后期统一（不管 AI 出什么都过一遍）

1. 色温向暖微调（+5~10）、饱和度 -5；
2. 叠 5~10% 水彩纸纹；
3. 裁切/抠图规范化为透明底正方画布；
4. 与 mockup 配色板并排比对（`docs/mockups/` 即风格对照样张）。

### 5.3 验收三张卡

每个素材入库前过三关：**剪影可辨吗？光源是左上吗？放进 mockup 里突兀吗？** 三关都过才算"同一套图"。

## 6. 美术如何服务留存（与内容的咬合点）

美术不是包装，是留存机制的一部分。四个明确的设计意图：

1. **情感母题「外婆的手抄本」**：图鉴=泛黄手抄本，每点亮一道食谱=本子上多一页手绘菜图+一行"外婆的字"。收集欲（支柱）从此有了情感钩子——玩家收集的不是数据，是外婆的记忆。成本极低（一个纸纹底 + 手写字体），回报是图鉴页从"列表"变成"宝物"。
2. **丰收祭的视觉承诺**：主线终章是"小镇重新热闹"。从 M2 起场景里就埋"沉睡的祭典元素"（田地远处挂着的褪色灯笼），章节推进时逐个被点亮——**画面随进度变化**是最强积累感外化（支柱 3），且只需做几张差分素材。
3. **惊喜时刻的仪式感**：发现新食谱 = 全屏唯一红点 + 星星贴纸爆开 + 菜谱翻页动画。爽点反馈必须贵，玩家才会为下一个组合付出时间（支柱 2）。
4. **现实时间制的温柔化**：等待是既定玩法，美术负责让"回来"有奖励感——上线时作物的生长差分图（幼苗→半熟→果实低垂）要一眼可见，成熟态加微微发光和轻摆动，让"回来看看"本身成为期待（支柱 1）。

## 7. 禁忌清单（违反任意一条即打回）

- 不用纯黑、纯灰、荧光色、冷蓝紫大面积铺色；
- 不做写实高光、金属质感、玻璃拟态；
- 不做直角矩形 UI、尖锐剪影；
- 不在下半屏画高细节背景；
- 不让红色出现在"可交互惊喜"以外的任何地方；
- 不混用光源方向不同的素材；
- 不为了"好看"加与玩法无关的装饰动效（每屏动效 ≤2 处，全部服务于反馈）。

## 9. 版本迭代路线（美术与功能同步）

**总原则（2026-07-23 方向核对确认）**：初版效果永远不是最终效果。美术不设独立里程碑，版本与功能里程碑绑定，随每次功能迭代同步变好、变"真"。参照系：动物餐厅、爆炒江湖——画风不复杂，但高度统一、细节生动、反馈精致；这个品类的"好"来自一致性与生命力，不来自渲染复杂度。

| 版本 | 对齐里程碑 | 目标 | 主要内容 | 状态 |
|------|-----------|------|----------|------|
| v1.0 | M2 垂直切片 | 风格基线："是一套图" | 色板/图形语言/管线锁定；29 图标；4 张场景大图；UI 皮肤化；3 个核心反馈动效 | ✅ 已完成（2026-07-22） |
| v1.1 | M3 内容填充 | 质感冲刺：从"统一"到"生动" | ①新内容资产同批产出（新作物/新食谱图标，过 §5.3 三关）；②菜品剪影多样化（碗/盘/杯/串/蒸笼分化，治"全是碗里色块"）；③作物生长阶段差分图进游戏 + 成熟态微光轻摆（§6 意图 4 落地）；④圆体/手写字体替换系统字；⑤纸纹叠层~~随 CDN 版场景图补回~~（2026-07-26 已本地先行：wcBg 水洗 + ui/paper 卡片叠层，CDN 版照旧）；⑥环境生气细节 1~2 处（炊烟/蒸汽/灯笼轻摆，守 §7 每屏动效 ≤2） | ✅ 全部落地：②③⑤（③含田地页场景化，2026-07-26），水彩质感套件；原型 v3 扩编 15 作物 × 40 食谱拼版（2026-08-04）；④站酷快乐体子集化接入（2026-08-05，ui.ttf 约 105KB）；⑥炊烟/大锅蒸汽代码动效（2026-08-05，田地/厨房各 1 处，零素材成本） |

执行纪律：

1. 每个功能里程碑必须带美术验收项，随里程碑验收一并过（对齐方案 §7.3）；
2. "越来越真"的指向是生活感与生命力（生长差分、动效、故事细节），不是提高画风复杂度——画风一经定稿不再摇摆，迭代只加"活"不加"派"；
3. 新素材入库必过 §5.3 三关，并与旧素材并排拼版比对才可合入；
4. 美术工作量计入对应里程碑周期，不额外膨胀范围（对齐 10h/周）。
