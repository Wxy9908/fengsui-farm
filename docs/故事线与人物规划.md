## 1. 定位：故事线在这款游戏里是什么

我们不是星露谷，没有角色移动、没有大地图漫游。《游戏开发方案》1.4 已锁定「可点击场景 + 热点区域 + UI 面板」，所以故事线**不是独立玩法模式**，而是包在现有经营循环外面的一层「意义与目标」：

- 给「做菜」一个顾客——菜品不再只是卖给抽象商店，而是端给具体的人；
- 给「赚钱」一个去处——金币和图鉴进度推进故事章节；
- 给「收集」一个情感钩子——每个 NPC 是一段小故事，图鉴之外多一套「人」的收集；
- **v2 增补**：给「交易」一张脸——商店不是菜单，是林婶的杂货铺；卖菜不是点按钮，是跟人打交道。

**一句话：经营循环不变，故事线负责回答「我在为谁种地、为谁做菜、在跟谁打交道」。**

### 不做清单（防膨胀，与首版同样严格）

- 不做分支网状剧情、不做选项影响结局——全部线性小节 + 收集解锁；
- 不做 NPC 日程/走动/好感下降等拟真系统——好感只升不降；
- 不做恋爱结婚——温情向，不做攻略向；
- 不加新 NPC（v2 定案：6 人加深，不扩编）；
- M5 不实装果园/养殖/钓鱼玩法（只预留数据接口，见 §7.4）。

## 2. 世界观与基调

**背景**：玩家回到儿时生活过的小镇「丰穗镇」，接手外婆留下的老农场和一间歇业多年的小食堂。小镇曾经以一年一度的「丰收祭」闻名，如今已停办多年，年轻人离开，铺子冷落。

> 定名留痕（2026-08-11）：游戏正式定名「**丰穗小镇**」——镇名即游戏名，本文档的世界观从此直接是游戏标题；品牌标志为金色麦穗徽章（详见《美术风格规范》版本记录）。

**主线一句话**：用一年的时间重新种出好菜、做出好菜，把「丰收祭」办回来，让小镇重新热闹起来。

**基调**（对齐已定「暖色田园」美术基调）：

- 暖、轻、慢——没有反派、没有死亡、没有失败惩罚，矛盾都是「小事」：一道做不出的菜、一个不好意思开口的请求；
- 幽默但克制——黑暗料理、失败试验可以是笑点素材，但不玩烂梗；
- 文案量级：单段对话 3~8 句，碎片化呈现，适配手机端与碎片时间，绝不铺大段文字墙；
- **v2 增补·温暖感的来源**：温暖不是靠"感人台词"堆的，是靠**细节的回响**——小满上次说想吃的东西，下次对话里他还记得；白婆婆讲过的往事，会在丰收祭上被另一个人提起。文案设计必须维护这种「镇上的事大家都记得」的感觉（§9 文案规范有检查项）。

## 3. 系统结构：三件套 + 声望轴

故事线由三个互相咬合的系统加一条进度轴组成，全部数据表驱动（沿用《数据表设计》「配置只读 / 存档运行时」分离原则）。

### 3.1 NPC 系统（`data/npcs.json`）

每个 NPC 是一份配置：身份、性格、喜好菜品、最爱菜、好感等级阈值、解锁的对话与奖励。详见 §4 人物表。

### 3.2 NPC 交易系统（`data/orders.json` 或动态生成规则）——本块的地基，最先做

v2 将 v1 的「订单」升级为「NPC 交易」，三种形态：

| 形态 | 说明 | 定位 |
|------|------|------|
| **求购单** | NPC 要某道已发现食谱的菜（或作物），限时/不限时交付；报酬 = 售价 × 溢价（1.2~1.5）+ 好感 | 主力形态，菜品第二出口 |
| **赠送** | 玩家主动送 NPC 喜欢的菜（每日限次防刷），回报好感 + 偶发回礼线索 | 好感的日常来源，零压力社交 |
| **以物易物** | 少数剧情交易：NPC 用种子/线索/专属食谱换指定菜品（不涉金币） | 剧情节点专用，手配 |

- 设计意义（沿用 v1，依然成立）：
  - 菜品第二出口且溢价高于直卖——回应「直接卖 vs 做菜」定价取舍（该悬案 2026-08-11 已由数值裁决收口，交易系统是体验层的呼应）；
  - 交易目标 = 天然的每日/每阶段小目标，解决前期「等待成熟时无事可做」的节奏问题；
  - 求购单要求「已发现的食谱」→ 玩家为接更好的单主动试新组合——给支柱 2 装发动机。

**商店人格化（v2 新增）**：商店页 = 「林婶的杂货铺」。分两期走——
- 一期（M5-1，纯文案/呈现层，机制零改动）：页面标题、卖出确认、今日特价黑板、缺货提示全部改为林婶口吻（「这个价给你，别跟外人说」）；
- 二期（交易系统上线后）：林婶成为真实的批量交易对象（批发单、订单刷新增益的来源人设）。

### 3.3 好感度与剧情系统（`data/stories.json`）

- **v2 定案：好感数据层前置 M5-1**——`npcs.json` 的好感阈值与存档 `affinity` 字段随交易系统一起落地，交易/赠送当即开始累计（先记账后开花）；M5-2 只做剧情解锁与 UI 呈现。
- 好感来源：完成交易（主）+ 赠送喜欢的菜（辅，每日限次）+ 送出「最爱菜」有额外加成（§4 每人标注）；
- 好感升级解锁三类奖励，按优先级：
  1. **剧情对话**：该 NPC 的支线小节（v2 加深为 8~10 段/人，见 §4）；
  2. **专属食谱**：NPC「教你一道菜」——食谱自动点亮进图鉴，食材仍需自己种。**食谱发现第二渠道**，专属食谱标记 `source:"npc"`，组合解析跳过，不与组合表重叠；
  3. **经营增益**：种子折扣、订单溢价提升、厨房队列+1 等——全部复用现有数值体系，不引入新机制。
- 剧情触发条件数据化：`{type:"affinity", npc, level}` / `{type:"recipesDiscovered", count}` / `{type:"reputation", level}` 等。

### 3.4 小镇声望轴（v2 新增，`reputation`）

用户定案：数值不能只有金币，需要更多维度的阶段性提升。设计：

- **定义**：声望 = 玩家在小镇的「人缘与口碑」，与农场等级并列的第三进度轴（金币=支付手段、农场等级=经营深度、**声望=人际关系广度**）；
- **来源**：完成 NPC 交易（按单计）、好感升级、主线章节推进、丰收祭相关行为——全部来自"与人打交道"，种地卖菜本身不涨声望（双轴分工清晰）；
- **用途（门控，不设消耗）**：高阶求购单解锁（T3/T4 菜品单要声望等级）、NPC 信任剧情（某些支线小节要声望门槛）、丰收祭筹备资格（第四章主线条件之一）；
- **阶段性提升**：声望等级用镇民称呼体现（外乡回来的 → 食堂的 → 自己人 → 丰穗镇的骄傲……），升级复用现有庆祝层播仪式感；
- **数值原则**：曲线与农场等级解耦但节奏对齐（正常游玩下两轴前后脚升级）；表结构入《数据表设计》，存档字段 `reputation`，`??=` 迁移。

### 三件套+声望轴与三大支柱的对齐审判

| 系统 | 支柱1 收获期待 | 支柱2 组合惊喜 | 支柱3 经营积累 |
|------|--------------|--------------|--------------|
| NPC 交易 | 订单催你种特定作物，收获有了"人等"的期待 | 接单需要先发现食谱 → 主动试组合 | 交易溢价 + 每日目标 |
| 好感/剧情 | NPC 喜欢的菜引导种植方向 | 专属食谱 = 新的发现时刻 | 好感奖励增益经营效率 |
| 声望轴 | 高阶单要求更稀罕的作物 | 声望解锁的高阶单牵引探索 T3/T4 组合 | 称呼进阶 = 长期积累的可见刻度 |
| 主线章节 | 章节目标要求集齐作物/菜品 | 章节食谱只能靠探索补全 | 丰收祭 = 长期积累的验收仪式 |

**结论：全部落在支柱上，无一项削弱核心循环。**

## 4. 首发人物表（6 人 · v2 深写版）

设计原则：数量克制（文案成本 = 人数 × 段数）；每人必须有**功能定位**与**情感弧线**；喜好绑定现有 15 作物 / 40 食谱，不等人设倒逼新内容。支线小节标题为 AI 起草大纲，写作时允许微调。

### 4.1 田伯（tianbo）

- **身份**：隔壁退休老农，看着玩家长大；外婆的老邻居。
- **性格**：嘴硬心软，见不得地荒着；夸人只会说「还行」。
- **功能**：新手引导的人格化 + 种子相关（种子折扣、稀有种子线索）。
- **喜好/最爱**：烤面包（最爱）、香煎土豆饼、全麦面包、盐水花生。
- **人物小传**：种了一辈子地，儿女在城里，劝不动他搬走。玩家外婆走后，他默默帮忙照看田地，嘴上说是「怕地荒了碍眼」。
- **支线大纲（9 段）**：①教你下种（引导兼任）→ ②嫌弃你种的番茄「秧子太瘦」→ ③偷偷帮你锄了草死不承认 → ④讲年轻时和他爹赌气三天不说话的事 → ⑤第一次夸你的烤面包「还行」（好感节点）→ ⑥拿出外婆当年托他保管的一袋老种子 → ⑦下雨天坐在田埂上说起外婆 → ⑧承认自己老了，地以后是你的了 → ⑨丰收祭前夜，他把珍藏的农具擦得锃亮送来。
- **情感弧线**：从「监工」到「托付」。

### 4.2 林婶（linshen）

- **身份**：杂货店老板娘，小镇情报站；商店页的人格化形象。
- **性格**：热心肠，算盘打得精；嘴上全是生意，心里全是人情。
- **功能**：批量交易（批发单/多单）、订单刷新增益、商店全部文案的口吻来源。
- **喜好/最爱**：番茄炖土豆（最爱）、馒头、白菜盒子、香辣土豆丝。
- **人物小传**：一个人撑起小店十几年，全镇谁家添丁、谁跟谁拌嘴她都知道——但收情报的代价是一道菜。店快撑不下去过，是玩家外婆常来照顾生意才熬过来的。
- **支线大纲（9 段）**：①开业大吉她第一个来下单（试探你手艺）→ ②教你「卖菜的学问」（引导兼任）→ ③透漏第一条情报：沈先生来镇上了 → ④压你价被你拒绝，反而高看你一眼 → ⑤讲外婆当年赊账也要救济她的事 → ⑥批发单玩法解锁（信任节点）→ ⑦她的账本里有一页记满了外婆的「赊账」，一笔都没催过 → ⑧提议恢复丰收祭，并主动承包物资采买 → ⑨丰收祭当天她的店挂出「今日歇业，去帮忙」。
- **情感弧线**：从「生意人」到「自己人」。

### 4.3 小满（xiaoman）

- **身份**：上小学的皮孩子，放学后蹲厨房门口。
- **性格**：馋、直球、说话不过脑子；全镇唯一真心爱吃黑暗料理的人。
- **功能**：低级订单 + 笑点担当 + 黑暗料理去处（彩蛋线）。
- **喜好/最爱**：爆米花（最爱）、草莓酱、玉米土豆饼、胡萝卜土豆泥；隐藏：黑暗料理（真爱）。
- **人物小传**：爸妈在城里打工，跟着爷爷奶奶过。肚子永远饿，嘴巴永远甜。他管玩家叫「做饭的」。
- **支线大纲（8 段）**：①蹲在门口被香味钓进来 → ②用一颗玻璃珠「买」你的爆米花 → ③给你起外号 → ④偷吃被林婶抓包（交集剧情 A）→ ⑤生日愿望是「天天有爆米花」→ ⑥第一次吃到黑暗料理说「比我奶奶做的强」（彩蛋线开启）→ ⑦帮你给沈先生递纸条打探消息 → ⑧丰收祭上宣布「我长大要当做饭的」。
- **情感弧线**：从「馋猫」到「小尾巴」。

### 4.4 沈先生（shenxiansheng）

- **身份**：路过的落魄美食评论家，暂住镇上。
- **性格**：挑剔毒舌，但其实在找「小时候的味道」。
- **功能**：高级订单（T2/T3 菜品）+ 专属食谱主力（×2）。
- **喜好/最爱**：南瓜浓汤（最爱）、丰收汤、蜜桃草莓挞、烤香菇。
- **人物小传**：曾经一篇食评能决定一家店生死，如今过气，写不动了。来丰穗镇是逃避，也是寻找——他小时候在外婆家吃过一碗汤，此后再没吃到过。
- **支线大纲（10 段）**：①对你的菜给出第一个毒舌评价 → ②林婶情报：他住的旅馆房钱快付不起了 → ③破例点了第二道菜（转机）→ ④教玩家第一道专属食谱（「看在你不烦我的份上」）→ ⑤白婆婆尝了他的菜说出往事（交集剧情 B 开启）→ ⑥他承认自己在找一碗汤 → ⑦教第二道专属食谱，手抖了 → ⑧玩家做出丰收汤，他沉默了很久说「还差一味」→ ⑨白婆婆那碗汤端上来，他哭了（主线三章收束）→ ⑩丰收祭食评只写了一句话：「此味只应故乡有。」
- **情感弧线**：从「逃兵」到「还乡」。

### 4.5 白婆婆（popo）

- **身份**：独居老人，玩家的外婆生前最好的朋友。
- **性格**：温吞，记性时好时坏；记得四十年前的事，忘了昨天的事。
- **功能**：温情线主担当，讲过去的事；厨房/图鉴引导的口吻来源；丰收祭关键回忆。
- **喜好/最爱**：玉米南瓜粥（最爱）、南瓜饼、胡萝卜土豆泥、葡萄果酱。
- **人物小传**：和玩家外婆从扎羊角辫时就认识。外婆走后她常来食堂门口坐一会儿，什么也不说。她的记忆像一本被水泡过的相册，翻到哪页算哪页——但关于外婆的那几页，格外清楚。
- **支线大纲（9 段）**：①在门口坐着，把你错认成外婆小时候 → ②教你摆碗筷的讲究（引导兼任）→ ③讲外婆第一次做砸菜的糗事 → ④「差一点提示」人格化：黑暗料理出锅时她说「少放了一样东西」→ ⑤拿出外婆借她再没还的旧头巾 → ⑥讲起丰收祭当年的灯笼 → ⑦记忆突然清晰，说出外婆拿手菜的秘密（主线关键）→ ⑧把那道汤做给沈先生（交集剧情 B 收束）→ ⑨丰收祭上她坐在外婆从前的位置，笑得像个孩子。
- **情感弧线**：从「遗忘」到「记得」。

### 4.6 阿远（ayuan）

- **身份**：四处流浪的年轻旅人，丰收祭前来到镇上。
- **性格**：神神秘秘，什么都知道一点；嘴严，但从不说谎。
- **功能**：主线引路人 + 稀有线索 + 终章关键物品持有者。
- **喜好/最爱**：草莓西瓜冰（最爱）、西瓜汁、丰收果盅、葡萄西瓜饮。
- **人物小传**：走南闯北，行囊里只有一口旧铝锅和半张烧焦的菜单。他似乎认识玩家的外婆——这条悬念是主线暗线，M5 全程不揭底，终章才揭开：他年轻时逃荒路过丰穗镇，是外婆的一碗饭救了他，他是回来还愿的。
- **支线大纲（8 段）**：①用一枚外地铜钱换一杯西瓜汁 → ②说出三种他从没见过的作物名字（他去过很多地方）→ ③林婶查他底细一无所获（交集剧情 C）→ ④帮你找到稀有种子线索 → ⑤半张烧焦的菜单第一次露面 → ⑥他说「这个镇子欠它一场丰收祭」→ ⑦亮出外婆当年写给他的那张菜单残页（主线四章）→ ⑧丰收祭后他悄悄离开，留下铝锅：「锅留下，我还得赶路。」
- **情感弧线**：从「过客」到「归人」（虽然再次离开，但已不是流浪）。

### 4.7 人物关系网（v2 加密：从注释变成可玩内容）

- 田伯 ↔ 白婆婆：旧识，田伯记得白婆婆爱喝的粥要熬到开花；
- 林婶 ↔ 所有人：情报站，但她自己的心事只有外婆知道（现在讲给玩家听）；

## 9. 文案规范（v2 新增）

**语气指南**：暖、轻、慢；幽默克制，不玩烂梗；每个人有口癖（田伯「还行」/林婶打算盘/小满直球/沈先生掉书袋/白婆婆重复半句话/阿远话留半句）。

**硬规则**：

1. 单段对话 3~8 句，超了拆段；
2. 每条引导/教学先是一句「人物会说的话」，再夹带操作信息；
3. **回响检查**：新对话不得与已有细节矛盾；尽量回收前文埋的钩（小满的爆米花、白婆婆的头巾、沈先生的汤）；
4. 菜品 desc 2~3 句：第一句写味道，第二句写人；
5. 不出现：死亡直白描写、说教、网络热梗、超出 15 作物/40 食谱的食材名。

**协作流程**：AI 按本规范起草 → 用户审定稿 → 修改留痕入《开发日志》。

## 10. 叙事化新手引导（2026-08-05 定案：新手引导并入故事线）

**形态**：轻量对话层，触发式对话气泡 + 常驻跳过 + 存档已读不重播（`readTutorials`，`??=` 迁移；老存档缺省视为已读）。

- **角色分工**：田伯=田地全部教学；林婶=商店经营；白婆婆=厨房与图鉴（以「想起你外婆当年……」口吻带，埋主线伏笔）；
- **教学即人设**：田伯不说「点击地块播种」，而说「地荒着我看着难受。来，先把这袋小麦撒下去」；
- **「差一点提示」**：白婆婆在黑暗料理出锅时给出（「这味道……你外婆当年也这么试过，后来她少放了一样东西」）；
- **数据表驱动**：入 `data/stories.json`（`{type:"tutorial", trigger}` 节点），与剧情节点同管线。

**验收**：新档从开机到第一笔卖出，全程无系统弹窗式引导；跳过可用；已读不重复。
