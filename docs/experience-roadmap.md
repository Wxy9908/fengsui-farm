## 2. 四条体验线怎么加深

四条线**同向加深、不同步等长**：玩法里程碑可以先厚一条线，但每版结束时四条都要摸到该版底线（允许写「本版豁免：……」并留痕）。

### 2.1 画面（Visual）

| 阶 | 玩家应感到 | 典型交付 | 已到 / 目标 |
|----|------------|----------|-------------|
| V0 灰盒 | 能点、能懂 | 色块按钮 | ✅ M1 |
| V1 统一皮 | 「这是一款暖色田园游戏」 | 色板 + 四页场景 + 图标同源 | ✅ M2～M3（规范 v1.0/v1.1） |
| V2 可读贴纸感 | 「图标清楚、不太糊、不太 AI 脏」 | 粗描边、平涂、弱水彩；俯视场景；按 `即梦出图管线` 先旧后新小样签字后放量 | **M5-P1 目标**（规范 v1.3） |
| V3 有人有镇 | 「镇上有脸、有地方」 | NPC 头像规范落地、地图/地点视觉 | M5-P2+ / 规范 v2.0 |
| V4 节庆呼吸 | 「进度会改变镇子样子」 | 丰收祭灯笼点亮、场景差分 | 丰收祭章 / 规范预留 |

纪律：V2 阶段**不加装修系统、不加码动效**（现有炊烟/蒸汽可保留，不为本批重做）。

### 2.2 音乐（Audio）

| 阶 | 玩家应感到 | 典型交付 | 已到 / 目标 |
|----|------------|----------|-------------|
| A0 静音可玩 | 不依赖声音也能懂反馈 | — | ✅ M1～M2 |
| A1 操作有声 | 种/收/发现/卖听得懂 | 程序化 SFX | ✅ M3～M4 |
| A2 有背景气场 | 进游戏像进了小镇午后 | 循环 BGM（可 CDN） | ✅ M4 |
| A3 情绪分轨 | 发现/失败/节日听感有差 | 关键事件 jingle 或短垫乐 | M5 后按需，不挡 P1 |
| A4 场景分曲 | 田地/食堂/祭典不同气味 | 多 BGM 或分层 | 更后 |

纪律：音频授权与包体红线见方案；本批体验底线以「不破现有 A2」为默认，不强制升级到 A3。

### 2.3 人物（Characters）

| 阶 | 玩家应感到 | 典型交付 | 已到 / 目标 |
|----|------------|----------|-------------|
| C0 无人 | 纯系统 | — | ✅ M1～M3 |
| C1 有名字的出口 | 「菜可以卖给人」 | 林婶小铺口吻、求购单 | ✅ M5-P0b |
| C2 有人带路 | 「有人教我玩」 | 田伯/林婶/白婆婆引导气泡 | ✅ M5-P0c |
| C3 有一点记得我 | 「交过单后话不一样了」 | 每人 2～3 段薄好感 | **M5-P1 目标** |
| C4 有弧线 | 「这个人变了」 | 8～10 段/人 + 交集剧情 | M5-P2 |
| C5 有镇脸 | 「六个人撑起镇子」 | 头像、口头禅稳定、声望称呼 | P2+ / 美术 v2.0 |

### 2.4 故事（Narrative）

| 阶 | 玩家应感到 | 典型交付 | 已到 / 目标 |
|----|------------|----------|-------------|
| N0 无来历 | 直接种田 | — | ✅ 体验版前 |
| N1 知道为何回来 | 序章可跳过 | 文字序章（动画可后置） | ✅ M5-P0c（文字版） |
| N2 知道镇的心事 | 闲话里漏丰收祭一角 | 引导/薄好感里按 §6.4 漏料 | **M5-P1 起埋，P2 加厚** |
| N3 走过主线节拍 | 五章筹备到办祭 | 主线章节 + 声望门控 | M5-P2+ |

## 3. 铁律：双轨验收

每个里程碑（或 M5 内的 P0 / P1 / P2 批次）结束时：

```
玩法验收（方案 §7.3 / 该批验收标准）
        AND
体验底线（本文 §4 对应该批的清单）
        = 本批「开发完成」
```

- 玩法过了、体验底线没过 → **不算完**，优先补体验或显式降级底线并写入大事记。  
- 体验做超了、玩法没过 → **不算完**，先修循环。  
- 底线只写「必须有」；加分项写在「加分（不做不挡验收）」。

**签字人**：体验底线默认由你（制作人）过目；可用 mockup 截图 / 真机录屏 / 文档勾选。

## 5. 每开一个新批次时的固定动作

1. 在本文 §4 **写下该批体验底线勾选表**（可从预告改正式）。  
2. 对照 §2，标出本批要对齐的 V/A/C/N 阶。  
3. 底线与加分分开；加分写进停车场或下一批。  
4. 批次中途若砍范围：**先改本文底线**，再删任务。  
5. 批次结束：勾选 → 写《开发日志》一行 → 方案大事记一行（若里程碑级）。
