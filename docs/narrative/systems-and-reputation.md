## 3. 系统结构：三件套 + 声望轴

故事线由三个互相咬合的系统加一条进度轴组成，全部数据表驱动（沿用《数据表设计》「配置只读 / 存档运行时」分离原则）。

### 3.1 NPC 系统（`data/npcs.json`）

每个 NPC 是一份配置：身份、性格、喜好菜品、最爱菜、好感等级阈值、解锁的对话与奖励。详见 §4 人物表。

### 3.2 NPC 交易系统（`data/orders.json` 或动态生成规则）——本块的地基，最先做

v2 将 v1 的「订单」升级为「NPC 交易」，三种形态：

| 形态 | 说明 | 定位 |
|------|------|------|
| **求购单** | NPC 要某道已发现食谱的菜（或作物），限时/不限时交付；报酬 = 售价 × 溢价（1.2~1.5）+ 好感 | 主力形态，菜品第二出口 |
| **赠送** | 玩家主动送 NPC 喜欢的菜（每日限次防刷），回报好感 + 偶发回礼线索 | 好感的日常来源，零压力社交 |
| **以物易物** | 少数剧情交易：NPC 用种子/线索/专属食谱换指定菜品（不涉金币） | 剧情节点专用，手配 |

- 设计意义（沿用 v1，依然成立）：
  - 菜品第二出口且溢价高于直卖——回应「直接卖 vs 做菜」定价取舍（该悬案 2026-08-11 已由数值裁决收口，交易系统是体验层的呼应）；
  - 交易目标 = 天然的每日/每阶段小目标，解决前期「等待成熟时无事可做」的节奏问题；
  - 求购单要求「已发现的食谱」→ 玩家为接更好的单主动试新组合——给支柱 2 装发动机。

**商店人格化（v2 新增）**：商店页 = 「林婶的杂货铺」。分两期走——
- 一期（**P0b 起**，纯文案/呈现层）：页面标题、卖出确认、今日特价黑板、缺货提示全部改为林婶口吻（「这个价给你，别跟外人说」）；
- 二期（求购上线后）：林婶成为真实的批量交易对象（批发单、订单刷新增益的来源人设）。

### 3.3 好感度与剧情系统（`data/stories.json`）

- **定案：好感数据层已在 P0b 落地**——`npcs.json` 阈值与存档 `affinity` 随求购记账（先记账后开花）；**P1** 做薄层对话解锁，**P2** 深写与 UI 完整呈现。
- 好感来源：完成交易（主）+ 赠送喜欢的菜（辅，每日限次）+ 送出「最爱菜」有额外加成（§4 每人标注）；
- 好感升级解锁三类奖励，按优先级：
  1. **剧情对话**：该 NPC 的支线小节（v2 加深为 8~10 段/人，见 §4）；
  2. **专属食谱**：NPC「教你一道菜」——食谱自动点亮进图鉴，食材仍需自己种。**食谱发现第二渠道**，专属食谱标记 `source:"npc"`，组合解析跳过，不与组合表重叠；
  3. **经营增益**：种子折扣、订单溢价提升、厨房队列+1 等——全部复用现有数值体系，不引入新机制。
- 剧情触发条件数据化：`{type:"affinity", npc, level}` / `{type:"recipesDiscovered", count}` / `{type:"reputation", level}` 等。

### 3.4 小镇声望轴（v2 新增，`reputation`）

用户定案：数值不能只有金币，需要更多维度的阶段性提升。设计：

- **定义**：声望 = 玩家在小镇的「人缘与口碑」，与农场等级并列的第三进度轴（金币=支付手段、农场等级=经营深度、**声望=人际关系广度**）；
- **来源**：完成 NPC 交易（按单计）、好感升级、主线章节推进、丰收祭相关行为——全部来自"与人打交道"，种地卖菜本身不涨声望（双轴分工清晰）；
- **用途（门控，不设消耗）**：高阶求购单解锁（T3/T4 菜品单要声望等级）、NPC 信任剧情（某些支线小节要声望门槛）、丰收祭筹备资格（第四章主线条件之一）；
- **阶段性提升**：声望等级用镇民称呼体现（外乡回来的 → 食堂的 → 自己人 → 丰穗镇的骄傲……），升级复用现有庆祝层播仪式感；
- **数值原则**：曲线与农场等级解耦但节奏对齐（正常游玩下两轴前后脚升级）；表结构入《数据表设计》，存档字段 `reputation`，`??=` 迁移。

### 三件套+声望轴与三大支柱的对齐审判

| 系统 | 支柱1 收获期待 | 支柱2 组合惊喜 | 支柱3 经营积累 |
|------|--------------|--------------|--------------|
| NPC 交易 | 订单催你种特定作物，收获有了"人等"的期待 | 接单需要先发现食谱 → 主动试组合 | 交易溢价 + 每日目标 |
| 好感/剧情 | NPC 喜欢的菜引导种植方向 | 专属食谱 = 新的发现时刻 | 好感奖励增益经营效率 |
| 声望轴 | 高阶单要求更稀罕的作物 | 声望解锁的高阶单牵引探索 T3/T4 组合 | 称呼进阶 = 长期积累的可见刻度 |
| 主线章节 | 章节目标要求集齐作物/菜品 | 章节食谱只能靠探索补全 | 丰收祭 = 长期积累的验收仪式 |

**结论：全部落在支柱上，无一项削弱核心循环。**
