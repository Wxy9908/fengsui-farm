## 10. 叙事化新手引导（2026-08-05 定案；2026-09-28：并入 M5-P0c；触发改挂地点）

**形态**：轻量对话层，触发式对话气泡 + 常驻跳过 + 存档已读不重播（`readTutorials`，`??=` 迁移；老存档缺省视为已读）。

- **排期**：M5-P0c。序章（§2.1）若同期做，只在新档播一次；教学气泡在序章之后。
- **触发写地点，不写页面名**（§2.2）：`farm` 现在由田地页打开，`canteen` 由厨房页打开，`shop` 由小铺页打开。地图接上后只改「谁打开这个地点」，台词不动。
- **角色分工**：田伯 = 农场（种、收）；林婶 = 杂货铺（卖给她）+ 指出「想吃的人在各自的地方」（现在先用订单页顶着）；白婆婆 = 食堂（做菜、图鉴、黑暗料理的「差一点」）。
- **教学即人设**：田伯不说「点击地块播种」，而说「记得不，你小时候就爱往田里钻。来，这袋小麦咱俩一起撒」。
- **「差一点提示」**：白婆婆在食堂、黑暗料理出锅时给出（「这味道……跟你外婆当年糊弄灶台一个样。少放了一样东西——我说完了」）。
- **数据表驱动**：入 `data/stories.json`（`{type:"tutorial", place, trigger}`），与剧情节点同管线。
- **明确不做**：独立任务列表、成就板、遮罩锁定逐步操作；P0c 也不做地图本身。

**验收**：新档从序章（或跳过）到第一笔卖出/交单，无系统弹窗式引导；跳过可用；已读不重复；老存档不重播。
