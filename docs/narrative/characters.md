## 4. 首发人物表（6 人 · v2 深写版）

设计原则：数量克制（文案成本 = 人数 × 段数）；每人必须有**功能定位**与**情感弧线**；喜好绑定现有 15 作物 / 40 食谱，不等人设倒逼新内容。支线小节标题为 AI 起草大纲，写作时允许微调。

**视觉定妆（与文案分工）**：性格/口癖以本节为准；头像画法、裁切、出图流程以 `docs/art/art-style-guide.md` §4.4 与 `docs/art/jimeng-pipeline.md` 阶段 3 为准。定妆图目录 `docs/mockups/npc/`——现有 `sc1.png` 为**田伯方向样**（可用；入库前去水印、弱布纹）。林婶 / 白婆婆 / 外婆及其他人**尚缺定妆**，补齐前不放量 NPC 头像。**排期：等已有图标/背景重做完成后再做（先旧后新）。**

### 4.1 田伯（tianbo）

- **身份**：隔壁退休老农，看着玩家长大；外婆的老邻居——全镇公认的「爷爷型」人物。
- **性格**：和蔼慈善，像亲爷爷；总记得你小时候的趣事，逢人就夸「这孩子最棒」；遇事乐意上手帮忙，从不端架子。
- **功能**：新手引导的人格化 + 种子相关（种子折扣、稀有种子线索）。
- **定妆**：`docs/mockups/npc/sc1.png`（草帽、白须、慈祥笑眼——方向正确）。
- **喜好/最爱**：烤面包（最爱）、香煎土豆饼、全麦馒头、盐水花生。
- **人物小传**：种了一辈子地，儿女在城里，劝不动他搬走。玩家外婆走后，他默默照看田地；玩家一回来，他比谁都高兴——口袋里总揣着花生，嘴里总有你小时候的故事。
- **支线大纲（9 段）**：①教你下种（引导兼任），顺口扯起「你小时候拔草拔成庄稼」→ ②在林婶店里当众夸你「回来种菜，比城里那些工作强」→ ③主动帮你解决一块板结地/坏种子的麻烦 → ④下雨天坐田埂，讲你偷摘番茄被外婆逮住的糗事，笑得直拍腿 → ⑤尝到烤面包，逢人就说「全镇数第一」（好感节点）→ ⑥拿出外婆当年托他保管的一袋老种子 → ⑦讲起外婆，又绕回「这孩子从小就懂事」→ ⑧承认自己老了，地以后是你的了——语气是托付，不是失落 → ⑨丰收祭前夜，他把珍藏的农具擦得锃亮送来。
- **情感弧线**：从「护犊」到「托付」。

### 4.2 林婶（linshen）

- **身份**：杂货店老板娘，小镇情报站；商店页的人格化形象。
- **性格**：热心肠，算盘打得精；嘴上全是生意，心里全是人情。
- **功能**：批量交易（批发单/多单）、订单刷新增益、商店全部文案的口吻来源。
- **喜好/最爱**：番茄炖土豆（最爱）、馒头、白菜盒子、香辣土豆丝。
- **人物小传**：一个人撑起小店十几年，全镇谁家添丁、谁跟谁拌嘴她都知道——但收情报的代价是一道菜。店快撑不下去过，是玩家外婆常来照顾生意才熬过来的。
- **支线大纲（9 段）**：①开业大吉她第一个来下单（试探你手艺）→ ②教你「卖菜的学问」（引导兼任）→ ③透漏第一条情报：沈先生来镇上了 → ④压你价被你拒绝，反而高看你一眼 → ⑤讲外婆当年赊账也要救济她的事 → ⑥批发单玩法解锁（信任节点）→ ⑦她的账本里有一页记满了外婆的「赊账」，一笔都没催过 → ⑧提议恢复丰收祭，并主动承包物资采买 → ⑨丰收祭当天她的店挂出「今日歇业，去帮忙」。
- **情感弧线**：从「生意人」到「自己人」。

### 4.3 小满（xiaoman）

- **身份**：上小学的皮孩子，放学后蹲厨房门口。
- **性格**：馋、直球、说话不过脑子；全镇唯一真心爱吃黑暗料理的人。
- **功能**：低级订单 + 笑点担当 + 黑暗料理去处（彩蛋线）。
- **喜好/最爱**：爆米花（最爱）、草莓酱、玉米土豆饼、胡萝卜土豆泥；隐藏：黑暗料理（真爱）。
- **人物小传**：爸妈在城里打工，跟着爷爷奶奶过。肚子永远饿，嘴巴永远甜。他管玩家叫「做饭的」。
- **支线大纲（8 段）**：①蹲在门口被香味钓进来 → ②用一颗玻璃珠「买」你的爆米花 → ③给你起外号 → ④偷吃被林婶抓包（交集剧情 A）→ ⑤生日愿望是「天天有爆米花」→ ⑥第一次吃到黑暗料理说「比我奶奶做的强」（彩蛋线开启）→ ⑦帮你给沈先生递纸条打探消息 → ⑧丰收祭上宣布「我长大要当做饭的」。
- **情感弧线**：从「馋猫」到「小尾巴」。

### 4.4 沈先生（shenxiansheng）

- **身份**：路过的落魄美食评论家，暂住镇上。
- **性格**：挑剔毒舌，但其实在找「小时候的味道」。
- **功能**：高级订单（T2/T3 菜品）+ 专属食谱主力（×2）。
- **喜好/最爱**：南瓜汤（最爱）、丰收汤、蜜桃草莓挞、烤香菇。
- **人物小传**：曾经一篇食评能决定一家店生死，如今过气，写不动了。来丰穗镇是逃避，也是寻找——他小时候在外婆家吃过一碗汤，此后再没吃到过。
- **支线大纲（10 段）**：①对你的菜给出第一个毒舌评价 → ②林婶情报：他住的旅馆房钱快付不起了 → ③破例点了第二道菜（转机）→ ④教玩家第一道专属食谱（「看在你不烦我的份上」）→ ⑤白婆婆尝了他的菜说出往事（交集剧情 B 开启）→ ⑥他承认自己在找一碗汤 → ⑦教第二道专属食谱，手抖了 → ⑧玩家做出丰收汤，他沉默了很久说「还差一味」→ ⑨白婆婆那碗汤端上来，他哭了（主线三章收束）→ ⑩丰收祭食评只写了一句话：「此味只应故乡有。」
- **情感弧线**：从「逃兵」到「还乡」。

### 4.5 白婆婆（popo）

- **身份**：独居老人，玩家的外婆生前最好的朋友；镇上少数敢当面戳人的长辈。
- **性格**：唠叨又毒舌，外冷内热。嘴上不饶人，其实一直在暗中盯着你——怕你回家种田只是三心二意、玩票一场。前期让人很不适应；看到你真下功夫后，口气慢慢软，印象改观。
- **功能**：厨房/图鉴引导的口吻来源（刀子嘴版）；温情线后半程担当；丰收祭关键回忆。
- **喜好/最爱**：玉米南瓜粥（最爱）、南瓜饼、胡萝卜土豆泥、葡萄果酱。
- **人物小传**：和玩家外婆从扎羊角辫时就认识。外婆走后她常来食堂门口坐一会儿，表面上是「路过歇脚」，其实在盘点你有没有认真干活。她不轻易认人——认了，就是把你当你外婆那一脉的人。
- **支线大纲（9 段）**：①见面就叨叨：「城里回来种田？能撑几天？」→ ②教你摆碗筷的讲究（引导兼任），边教边挑刺 → ③你发现她总在门口「路过」，其实在盯你出工 → ④「差一点提示」人格化：黑暗料理出锅时她毒舌一句「少放了一样东西，跟你外婆当年糊弄灶台一个样」→ ⑤第一次改观：你连晴带雨都下地，她递来外婆借她再没还的旧头巾（嘴上仍硬：「拿去擦汗，别热傻了」）→ ⑥讲起丰收祭当年的灯笼，口气罕见地软 → ⑦正式认你，说出外婆拿手菜的秘密（主线关键）→ ⑧把那道汤做给沈先生（交集剧情 B 收束）→ ⑨丰收祭上她坐在外婆从前的位置，唠叨变成夸赞，只是夸得很别扭。
- **情感弧线**：从「戒备」到「认你」。

### 4.6 阿远（ayuan）

- **身份**：四处流浪的年轻旅人，丰收祭前来到镇上。
- **性格**：神神秘秘，什么都知道一点；嘴严，但从不说谎。
- **功能**：主线引路人 + 稀有线索 + 终章关键物品持有者。
- **喜好/最爱**：草莓西瓜冰（最爱）、西瓜汁、丰收果盅、葡萄西瓜饮。
- **人物小传**：走南闯北，行囊里只有一口旧铝锅和半张烧焦的菜单。他似乎认识玩家的外婆——这条悬念是主线暗线，M5 全程不揭底，终章才揭开：他年轻时逃荒路过丰穗镇，是外婆的一碗饭救了他，他是回来还愿的。
- **支线大纲（8 段）**：①用一枚外地铜钱换一杯西瓜汁 → ②说出三种他从没见过的作物名字（他去过很多地方）→ ③林婶查他底细一无所获（交集剧情 C）→ ④帮你找到稀有种子线索 → ⑤半张烧焦的菜单第一次露面 → ⑥他说「这个镇子欠它一场丰收祭」→ ⑦亮出外婆当年写给他的那张菜单残页（主线四章）→ ⑧丰收祭后他悄悄离开，留下铝锅：「锅留下，我还得赶路。」
- **情感弧线**：从「过客」到「归人」（虽然再次离开，但已不是流浪）。

### 4.7 人物关系网（v2 加密：从注释变成可玩内容）

- 田伯 ↔ 白婆婆：旧识；田伯总在她面前护着你，白婆婆嫌他「把孩子夸傻了」，心里却记下他的每句好话；田伯记得她爱喝的粥要熬到开花；
- 林婶 ↔ 所有人：情报站，但她自己的心事只有外婆知道（现在讲给玩家听）；
- 沈先生 ↔ 林婶：嫌她的店「没有审美」，林婶嫌他「穷讲究」——交集剧情里两人达成微妙和解；
- 小满 ↔ 沈先生：怕他又忍不住靠近厨房，是两人各自的支线串联点；
- 阿远 ↔ 外婆（已故）：主线暗线，终章揭开；
- 白婆婆 ↔ 沈先生：一碗汤连接两个人（交集剧情 B）。

## 5. 人物交集剧情（v2 新增）

跨 NPC 事件，触发条件 = 两个 NPC 各达指定好感 + 前置小节完成；呈现为**双方同时在场的对话小节**（数据上 `stories.json` 节点标 `participants:[a,b]`）。首发三组：

| 编号 | 名称 | 参与 | 内容一句话 | 触发 |
|------|------|------|-----------|------|
| A | 偷吃风波 | 小满 × 林婶 | 小满偷吃被林婶抓包，林婶罚他「用劳动抵债」，玩家出面调停 | 小满好感 2 + 林婶好感 2 |
| B | 那碗汤 | 白婆婆 × 沈先生 | 沈先生寻找的「小时候的味道」正是外婆的汤，白婆婆是唯一还记得做法的人 | 沈先生支线 ⑥ + 白婆婆支线 ⑦ |
| C | 查户口 | 林婶 × 阿远 | 林婶查阿远底细一无所获，反而被他点破她藏了多年的心事 | 阿远支线 ③ + 林婶好感 3 |
