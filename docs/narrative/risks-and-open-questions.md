## 11. 风险与对策

| 风险 | 对策 |
|------|------|
| 文案工作量失控（最大风险，业余 10h/周） | 6 人锁死；深写前先 P1 薄层测成本；AI 起草用户审 |
| 交易溢价破坏经济 | sim 仿真断言：交易时薪 > 做菜直卖时薪 > 作物直卖时薪，三层关系守住（参照 2026-08-11 数值裁决口径） |
| 声望轴与农场等级混淆 | 分工写死：等级管「资格与购买」，声望管「人与剧情」；种地不涨声望，交易不涨经验 |
| 专属食谱与组合发现冲突 | `source:"npc"` 标记，组合解析跳过 |
| 老存档兼容 | 全部新字段 `??=` 迁移；主线按图鉴数/金币/声望推算接入章节 |
| 深写后人物 OOC（性格漂移） | §9 文案规范口癖表 + 用户审定稿环节 |
| 地图与分页两套入口并存太久 | 触发一律用 `place`；订单页标明临时；地图期只替换入口 |
