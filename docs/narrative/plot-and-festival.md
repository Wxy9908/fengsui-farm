|----|-------------|------|---------|-------------|
| 序 | 回镇 | 新档第一次进入 | 看完或跳过 §2.1 | 从进村路走进来，田伯在农场等；不计入五章进度 |
| 一 | 重新开张 | 序章结束（老存档视为序章已读，直接本章） | 发现 5 道食谱 | 田伯在门口把你接回来，决定重开食堂。旧围裙若序章已随信带到，本章改为系上，不再寄一次 |

### 6.3 季节/节日线（最后做，可再分期）

- 现实日期触发的节日交易与限定对话（春节、中秋等，现实时间制的天然优势）；
- 依赖主线+支线管线验证，**不进入 M5 首版范围**。
- 丰收祭不走这条线。它由章节推进，在镇中空地办一夜；第二年复办仍是故事里的一夜，不绑某一天的现实日期。

### 6.4 丰收祭：来历、过法、对每个人的意义（2026-09-28）

写作用。节日是主线的终点，也是前面每段闲话要慢慢喂给玩家的东西。单段仍守 3~8 句，本节是作者心里的全貌，角色每次只说出自己那一角。

**为什么会有这个节日**

丰穗镇种得出粮食以后，有过一年收成薄、各家把粮关在自己屋里。镇中那块空地（村口与食堂之间，见地图）上，有人把自家剩的一口饭摆出来，说：薄年也坐在一起吃，丰年也坐在一起吃。后来每年收完最后一茬，就在这空地上摆长桌。麦穗是那年桌上第一样能分的粮食，镇名、游戏名、金色麦穗徽章都从这一晚来。

它庆的是「这一年的收成放到同一张桌上」，不是评比谁种得最好，也没有祭司、比赛、冠军。食堂在镇中间，因为这张桌的热菜从食堂端出来。外婆在的那些年，她是这口灶的人。

**为什么停了**

没有人宣布取消。年轻人去了城里，食堂歇了，凑不齐一桌人，也没有人把热菜端到空地中央。灯笼还挂在田边，一年年褪色。停办是人少了、灶冷了，不是一场灾，也不是谁的过错。

**当晚怎么过**（终章按这个顺序演，前面章节只预告其中一两步）

1. 白天，田伯把这一年地里的东西摆到空地上给人看。摆出来就行，不打分。
2. 林婶的杂货铺挂上「今日歇业，去帮忙」。桌、碗、灯笼由她备。
3. 午后，小满沿着镇路把褪色的灯笼点上。田地页远处那串灯笼，就是这些。
4. 黄昏，食堂出三道摆在长桌正中的菜，用的是现有食谱，不新做菜：
   - **烤面包**：这一年的麦，田伯的最爱，放在最前；
   - **番茄炖土豆**：铺子里的家常，林婶的最爱；
   - **丰收汤**：沈先生私下找了一整章的那碗，这晚端到大家面前。
   其余的人各带自己的一碗。白婆婆带玉米南瓜粥，不算这三道，是她自己的那一碗。
5. 长桌一头留着外婆从前的位子。白婆婆只有认定食堂又开了，才会坐下去。她不致辞，尝一口，再挑别人的咸淡。
6. 沈先生不写长文，只留一句：「此味只应故乡有。」
7. 阿远吃完，天亮前从进村路离开，把铝锅留下。他还的是许多年前的一碗饭，不是留下来住。

**对每个人意味着什么**

| 谁 | 这个节日对他是什么 | 玩家会看见的样子 |
|----|--------------------|------------------|
| 玩家 | 这一年种和做的验收。空地坐满人，主线才算到头 | 终章在空地过完上述一夜 |
| 田伯 | 地还在这家人手里。他要的是农具被用过、收成摆上桌 | 前一夜把擦亮的农具送来；白天负责把收成摆出来 |
| 林婶 | 一年里唯一不算账的一天。铺子能歇业去帮忙，镇就还是镇，不是一份客人名单 | 第二章由她说出节日的名字并提议办回来；当天歇业 |
| 小满 | 食堂属于所有人的一夜，包括爸妈在城里的孩子。「做饭的」第一次像一种长大以后的事 | 点灯笼；祭上说自己长大要做饭 |
| 沈先生 | 那碗汤不再是他一个人的考试。他承认故乡的味道排不了名次 | 第三章私下喝到汤；祭上只留那一句 |
| 白婆婆 | 她可以不再守着门口防你离开。坐上外婆的位子，就是认你留下了 | 中段讲灯笼；祭上坐下，夸你，夸得很别扭 |
| 阿远 | 还愿。他年轻时路过，外婆给过他一碗饭。节日办成，这碗饭就还了 | 第四章说镇子欠自己这一晚，并交出菜单残页；祭后离开 |
| 外婆 | 她是灶，不是谜底。信里不解释节日 | 彩蛋信仍不讲丰收祭；做法和位子由白婆婆、田伯慢慢说 |

**情节里怎么一点点丰满**（每次只漏一角，后文要接住前文的原话）

| 时候 | 玩家新知道的 | 谁说 | 先别说破 |
|------|----------------|------|----------|
| 第一章，田埂上 | 以前收完庄稼，全镇会在空地上吃一晚，田边挂着灯笼 | 田伯，教下种时顺嘴一句 | 节日的名字、为什么停 |
| 第二章章末 | 它叫丰收祭。杂货铺那天会歇业。她问要不要办回来 | 林婶 | 三道菜、外婆的位子 |
| 白婆婆中段好感 | 灯笼是祭上点的。她难得把声音放软 | 白婆婆 | 她会不会去坐那个位子 |
| 第三章 | 沈先生找的汤，和「全镇一起吃的那晚」是同一口灶 | 白婆婆、沈先生 | 阿远手里的菜单 |
| 第四章 | 长桌正中要三道菜；残页是外婆写给祭典的菜单。声望到「自己人」，才够资格为这张桌做菜 | 阿远，众人动员 | 他当年为什么吃过这口灶 |
| 第五章 | 按「当晚怎么过」演完。他离开时可以点明：许多年前的一碗饭 | 所有人 | 彩蛋信仍然不讲这些 |

第二年再办时，沿用同一夜的过法，对白改成「去年你也在」，不再加新的身世。
