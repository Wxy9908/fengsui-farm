## 8. 分期路线图（故事侧要点）

**批次编号与完成状态（✅/待做）真源 → `docs/development-plan.md` §6.5～§6.6，本文不维护状态勾选。**  
体验底线勾选 → `docs/experience-roadmap.md` §4。

下表只列各批次**故事/文案侧**交付要点（与方案对齐，无状态列）：

| 批次 | 故事侧要点 |
|------|------------|
| M5-P0a 前期节奏 | 无故事交付 |
| M5-P0b 求购 + 好感记账 + 林婶文案 | 林婶口吻一期；affinity 先记账不开花 |
| M5-P0c 对话引导 | 田伯/林婶/白婆婆地点气泡（§10）；序章短文可跳过；无任务板 |
| M5-P0d 菜谱可信度 | 菜名家常化（组合表 §4.2）；无新剧情 |
| M5-P1 好感薄层 + 静态画风 | **前期三人**（田伯/白婆婆/沈先生）薄好感 2+2+1+出锅；林婶等延后；画风见体验文档 / 美术规范 |
| M6-P0 | 地图 + 背包；故事仅保证 `place` 与热点一致，无长篇交付 |
| M6-P1 | 果园；田伯等可在 farm/orchard 热点露面（见面级，不挡玩法验收） |
| M6-P2 | 人物出场完整 + **订单绑地点** + 交单好感主路径；薄好感/祭典漏料按准备稿铺量 |
| M6 之后 | 深写 8~10 段/人、交集、专属食谱、声望称号、丰收祭五章、装饰 |

声望完整呈现随 M6 之后批次；M6-P2 前好感剧情冻结推广（见 `affinity-design.md` 文首）。
