# M6 小镇扩展（玩法批次说明）

> **角色**：M6 **做什么、先做什么、硬性验收** 的展开说明（里程碑状态只改 `development-plan.md` §6）。  
> **真源**：本文 §2～§4；字段细则 → `gameplay/data-schema.md`；批次 ✅ → 方案 §6.6。  
> **不写**：对白全文、即梦提示词、提审清单（→ `release/`）。  
> **文档分工**：`docs/doc-governance.md`

- 定案：2026-10-09
- 原则：**玩法升级优先**；人物随地点出场；**订单与完整好感线排在人物基础之后**。正式上线顺延为 **M7**（原「M6 提审」项）。

---

## 1. 与旧 M5 的关系

- **M5** 视为已收口（P0 + P1 体验线）；体验版上已有的订单 tab / 交单好感 **代码可保留**，产品顺序按 M6 重排（见 §4）。
- 叙事与引导的**历史文案矛盾本期不统一修**；以本文与数据字段为准推进实现。

---

## 2. 硬性指标（M6 整体验收）

| # | 必做 | 验收要点 |
|---|------|----------|
| H1 | **果园玩法闭环** | 独立 `place: orchard`（地图热点进入）；草莓/西瓜/葡萄/桃子仅在果园种植收获；与田地循环共用 Core，分场景数据驱动 |
| H2 | **`crops.json` 的 `type`** | 标明每种作物应在哪类场景种植；见 `data-schema.md` §2 |
| H3 | **小镇地图** | 可点热点进入 farm / orchard / canteen / shop（对齐 `mockups/map.svg`）；可与底栏短期并存 |
| H4 | **背包页** | **H4a** 功能 MVP：抽屉 + 分类库存（P0-B1 ✅） · **H4b** 内页视觉改版（`gameplay/bag-ui-design.md`）— **H4b 未过则 M6 整体验收不算完成** |
| H5 | **人物基础出场** | 地图上对应地点可见 NPC（立绘/头像/气泡入口）；每人见面级内容（文案准备可复用 `characters` / `stories`） |
| H6 | **订单 + 交单好感（产品序）** | **M6-P2 完成后**再作为玩家主路径：订单绑定 NPC+地点；体验版订单 tab **弱化或隐藏至 P2** |

**本期不做（仍停车场）**：渔场、养殖、装修、独立任务板、声望轴完整 UI、丰收祭主线实装。

---

## 3. 推荐实施顺序

| 批次 | 内容 | 依赖 |
|------|------|------|
| **M6-P0** | 地图壳 + 背包**功能 MVP** + 路由（热点进现有田地/厨房/小铺 UI）；**功能锁**按 `gameplay/main-quest-design.md` 章一主线发放 | — |
| **M6-P0′** | 背包**内页改版**（网格 + tab，§ `bag-ui-design.md`） | P0 抽屉可开；可与 P1 并行，**挡 M6 收口** |
| **M6-P1** | `type` 字段 + 四水果迁果园 + 果园场景/坑位 + `npm run balance` | P0 地图能进 orchard |
| **M6-P2** | 人物地点出场 + 见面剧情；订单改绑地点；开放订单 tab / 交单好感为新档主路径 | P1 果园可玩 |

美术：果园场景/植株跟 P1 最小集同行；图标 W1A/W1B 可与 P1 并行，不挡 H1 逻辑验收。

---

## 4. 好感与订单（产品纪律）

- **M6-P2 之前**：`type: affinity` 节点**不应对新玩家主动展开**（实现上可冻结触发或仅保留已写条目不推广）；交单涨分可保留于代码，**不以订单 tab 为教学入口**。
- **M6-P2 起**：订单从「集中第五页」迁到 **人物所在 `place`**；好感主来源仍为交付，与 `affinity-design.md` 对齐。

---

## 5. 作物 `type` 与迁移（真值口径）

| type | 场景 place | 作物 id（M6-P1 目标） |
|------|------------|------------------------|
| `farm` | farm | 除下表外全部 15 作物中的 **11 种**（含香菇、花生；**不含**四水果） |
| `orchard` | orchard | `strawberry`、`watermelon`、`grape`、`peach` |

远期枚举预留（本期不落玩法）：`fishery`、`ranch` — 字段可先写入 schema 说明，表中不强行占行。
