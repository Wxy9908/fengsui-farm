## 6. 提示词模板（粘贴用）

### 6.0A 田里植株 · 全局前缀

```
【丰穗小镇·田里作物·全项目通用】
2D手绘游戏立绘小株，粗深棕描边略有手绘抖动，干净平涂，主体暖色平涂，可爱但能认作庄稼。
禁止：写实、3D、水彩大晕染、文字、水印、UI、白边贴纸外框、漂浮剪贴画、整页界面、一张图多个主体。
禁止：白底、奶油色实底、任何非透明背景板（游戏里叠在地块上，须透明 PNG）。
```

### 6.0B 背包贴纸 · 全局前缀

与 **§6.3B 代码块** 同步（作物列表图标以 §6.3B 为准；以下为摘要）：

```
【丰穗小镇·图标规范·全项目通用】
2D手绘游戏道具图标，粗深棕描边略有手绘抖动，干净平涂，主体暖色平涂（麦黄/丰收黄等），圆润剪影，极简暖棕阴影，动物餐厅式可爱图标（不是实体贴纸刀模）。
禁止：写实、3D、水彩大晕染、文字、水印、UI角标、整页界面、一张图多个图标、白色外轮廓/刀模白边/灰黑投影光晕、3D立体贴纸。
禁止：白底、奶油色实底、#FFF8E7 纸张底、任何非透明背景板（程序要透明 PNG）。
```

### 6.0C 透明底纪律（图标 / 地里株 / 地图叠层）

下列资产入库后必须是 **透明 PNG**，提示词里 **不要** 再写「奶油底」「浅色纯底」「均匀浅奶油色背景」等实底用语：

| 类型 | 章节 |
|------|------|
| 作物收获贴纸、菜品图标 | §6.3B |
| 地图/背包入口 icon | §6.3C |
| 地里成熟株与 `_s1` / `_s2` | §6.3A |
| 地图地点 `map_place_*` | §6.4.1 |

**画面**行写 **透明底**，并写明禁止白/奶油方块底。前缀「主体暖色平涂」指 **填色气质**（对齐 `art-style-guide`），**不是**画布底色。整页场景（§6.4 背景、loading 海报、§6.5 半身像定妆）仍可用天空/草地/浅色实底。

### 6.3A 田里植株（阶段 0 主用 · 仅 dw13）

小麦成熟示例（已验证方向：带土、有手绘感）：

```
【丰穗小镇·田里作物·全项目通用】
2D手绘游戏立绘小株，粗深棕描边略有手绘抖动，干净平涂，主体暖色平涂，可爱但能认作庄稼。
禁止：写实、3D、水彩大晕染、文字、水印、UI、白边贴纸外框、漂浮剪贴画、整页界面、一张图多个主体。
禁止：白底、奶油色实底、任何非透明背景板（游戏里叠在地块上，须透明 PNG）。

只参考已上传图的线描与平涂气质，不要复制菜单和文字。
不要做成商品图标或周边贴纸；要做成能种在地里的作物植株。
不要画成简单几何符号或三个圆点插在杆子上。

描边粗细略有不均、带轻微手绘抖动，左右不要完全对称，
平涂但允许一点点颜料不均，不要完美矢量几何，
土壤边缘也要手绘感，不要光滑椭圆土团。

画面：透明底，1:1，植株直立，根部/土面在画面偏下，像从一小撮土里长出来；不要白底或奶油色方块背景。
内容：一丛成熟金黄小麦，多根麦秆聚成一小丛，穗头有麦粒层次，带绿叶，底部可见一小团棕色土壤或破土感，重心落地。
仍是平涂，不要写实摄影。
```

换作物：只改「内容：」那一行（其余整段前缀不动）。  
**小样命名（田里三档）**：目录 `docs/参考图/小样/icons/crops/` 内仅保留 `<id>.png`、`<id>_s1.png`、`<id>_s2.png`。即梦下载常带 `_抠图` 后缀 → 先 `npm run organize-crop-samples` 再 `npm run import-jimeng-crop-stages-all`（入库会去右下角「即梦AI」水印并抠透明/黑底）。被替换的旧文件进同目录 `_archive/日期/`。

#### `_s2` 防漂纪律（全作物通用）

1. 只写「半成/未成熟」不够，必须写清**颜色未转熟色 + 形体更小更疏**。  
2. 出 s2 时**不要挂**该作物成熟图作参考（只挂 dw13）；否则易照抄成熟色。——但提示词必须写清**与成熟同布局逻辑**（贴地的继续贴地，丛生的继续丛生）。  
3. 验收：与成熟小样并排，一眼能分 s1 / s2 / 成熟三档。  
4. **贴地作物**（南瓜/西瓜/圆白菜）：果或球必须**坐在土上**；禁止悬空挂果、禁止高脚杆/树状杆顶叶。  
5. **根菜**（胡萝卜）：s2 只允许「刚露尖」，大半截橙根探出＝成熟，区分度不够就重做。  
6. **实战纠偏（2026-09-30）**：`pumpkin_s2` 曾漂成茎中挂小瓜；`cabbage_s2` 曾漂成高杆顶叶；`carrot_s2` 曾几乎等同成熟——均已改内容行重跑。

### 6.3B 背包贴纸 / 菜品图标（仅 dw13）

**作物收获贴纸（15 个 `<id>.png`）**：用下面整段 + 下表「内容行」；**首批 7 作物 ✅ 2026-10-09**（`小样/icons/crops-ui/`）。  
**菜品**：同一模板，只改最后一行 `内容：`（盘装/碗装 SUBJECT）；**不要**写「从土里长出」。

```
【丰穗小镇·图标规范·全项目通用】
2D手绘游戏道具图标，粗深棕描边略有手绘抖动，干净平涂，主体暖色平涂，圆润剪影，极简阴影，动物餐厅式可爱图标（不是实体贴纸刀模）。
禁止：写实、3D、水彩大晕染、文字、水印、UI角标、整页界面、一张图多个图标。
禁止：白色外轮廓、白色刀模边、粗白描边、灰色投影光晕、3D立体贴纸、电商贴纸效果。
禁止：纯高光金属、冷灰阴影、食材拟人脸/五官/腮红。
禁止：白底、奶油色实底、#FFF8E7 纸张底、任何非透明背景板。

只参考已上传图的线描与平涂气质，不要复制菜单和文字。
光源统一左上45度，阴影用暖深棕、极轻，落在主体右下侧；不要左侧大块投影。
生成：单个游戏道具图标，1:1，居中，主体约占70%，背景完全透明，无白边、无奶油色方块、无渐变脏边。
深棕色（#4A3520）手绘描边画在透明底上，线条外侧不要再包一圈白边或色底。

内容：[SUBJECT，见下表或菜品描述]。
```
