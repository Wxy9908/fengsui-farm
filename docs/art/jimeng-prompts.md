### 6.3A 田里植株（阶段 0 主用 · 仅 dw13）

小麦成熟示例（已验证方向：带土、有手绘感）：

```
【丰穗小镇·田里作物·全项目通用】
2D手绘游戏立绘小株，粗深棕描边略有手绘抖动，干净平涂，暖奶油色，可爱但能认作庄稼。
禁止：写实、3D、水彩大晕染、文字、水印、UI、白边贴纸外框、漂浮剪贴画、整页界面、一张图多个主体。

只参考已上传图的线描与平涂气质，不要复制菜单和文字。
不要做成商品图标或周边贴纸；要做成能种在地里的作物植株。
不要画成简单几何符号或三个圆点插在杆子上。

描边粗细略有不均、带轻微手绘抖动，左右不要完全对称，
平涂但允许一点点颜料不均，不要完美矢量几何，
土壤边缘也要手绘感，不要光滑椭圆土团。

画面：浅奶油或浅色纯底，1:1，植株直立，根部/土面在画面偏下，像从一小撮土里长出来。
内容：一丛成熟金黄小麦，多根麦秆聚成一小丛，穗头有麦粒层次，带绿叶，底部可见一小团棕色土壤或破土感，重心落地。
仍是平涂，不要写实摄影。
```

换作物：只改「内容：」那一行（其余整段前缀不动）。  
文件命名：`docs/参考图/小样/icons/crops/<id>.png` / `<id>_s1.png` / `<id>_s2.png`。

#### `_s2` 防漂纪律（全作物通用）

1. 只写「半成/未成熟」不够，必须写清**颜色未转熟色 + 形体更小更疏**。  
2. 出 s2 时**不要挂**该作物成熟图作参考（只挂 dw13）；否则易照抄成熟色。——但提示词必须写清**与成熟同布局逻辑**（贴地的继续贴地，丛生的继续丛生）。  
3. 验收：与成熟小样并排，一眼能分 s1 / s2 / 成熟三档。  
4. **贴地作物**（南瓜/西瓜/圆白菜）：果或球必须**坐在土上**；禁止悬空挂果、禁止高脚杆/树状杆顶叶。  
5. **根菜**（胡萝卜）：s2 只允许「刚露尖」，大半截橙根探出＝成熟，区分度不够就重做。  
6. **实战纠偏（2026-09-30）**：`pumpkin_s2` 曾漂成茎中挂小瓜；`cabbage_s2` 曾漂成高杆顶叶；`carrot_s2` 曾几乎等同成熟——均已改内容行重跑。

### 6.4 俯视场景（田地背景 · 阶段 0.2）

**对齐现版 `assets/resources/bg/field.jpg` 的分层逻辑**（见 `sim/bg-lib.js` `field()`）：

| 画进背景 | 不要画（代码叠层） |
|----------|-------------------|
| 天空、太阳、云、远山、大树、小屋+炊烟、灯笼串、木栅栏 | 菱形/矩形田格、作物、人物、动物、收获篮 |
| 下半大面积**低细节草地**（可有轻微色斑，勿高细节花草家具） | **任何按钮/HUD/导航/文字/UI 占位框** |

**要不要预留按钮位置？**  
**不用画按钮轮廓。** 只要下半约 60% 保持低细节空地，顶栏/底导航/地块由程序盖在草地上。硬切一块纯奶油色空板、或画田格虚线，都不对。

```

2D手绘游戏场景，粗深棕描边，干净平涂，暖奶油色，动物餐厅式线语言，桃源式高俯视田园。
禁止：写实、3D、文字、水印、UI控件、按钮、导航栏、人物、动物、作物植株、田格线、菜畦网格、家具杂物堆。

画风只参考动物餐厅线描平涂气质；构图对齐「上半装饰、下半空操作区」，不要照抄桃源里的凉亭甲板、盆栽架、摇椅、兔子。
```
